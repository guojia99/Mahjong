## UI体验优化
1. 侧边栏在PC环境下可收起。收起为图标即可。
2. 麻将复盘盘在任何情况下固定为正方形，不能随容器大小膨胀缩放等，即强制宽高比例一致为1:1。
3. 前端对局列表更改为一行一个卡片（之前默认PC下为一行两个卡片）
4. 对局列表、线上牌谱统计切换tab、分页配置时，需要自动记录到query中，然后url自动记录到对应的配置，重新进入链接时需要自动切换分页等。
5. 点击进入对局列表时，返回时需要自动切换到之前的翻页配置。
