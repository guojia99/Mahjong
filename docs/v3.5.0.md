## 在线雀谜
- 基于当前离线版本的雀谜进行优化。
- 单独一个页面，但组件可复用。

### 后端
- 新增雀谜题谱，可由玩家登录后出题并提交，后端保存格式数据和前端一致的。
- 新增两个表
  - 题面表
  - 玩家答题表
- 玩家答题后，不允许再答题
- 玩家在前端获取到题面后，即开始答题。
  - 玩家每次提交一次答案，都需要进行反馈，并记录到数据库。
  - 次数用完或者则后续不再可提交。
- 玩家可以查看自己玩过的谜题，包括未完成的谜题。
- 玩家创建题目时，前后端都需要验证题出的否准确。
- 需要有一个列表来展示谁出了题。
- 每个人每天只能出10道题。

### 前端
- 答题流程和离线游戏一致。
- 出题时，选牌需要自动排序。
- 有出题列表，玩家可以点进列表里面。
- 每道题有单独的排行榜，自己出的题只能看，不能答题。
- 玩家可以删除没人玩的谜面。

### 管理员
- 管理员可以删除或禁用谜面，不受限制。
- 管理员可以禁止某些人出题，即黑名单。
