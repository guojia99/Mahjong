## 线上牌谱AI分析
- 我希望给我的项目接入Mortal
  - 当前服务放在了: [mortal-server](../mortal-server)
  - 接入文档为: [README.md](../mortal-server/README.md)
  - 解答文档： [mortal_FAQ.md](../mortal-server/mortal_FAQ.md)
  - 该服务已经是验证过可用的了，你仅可依据需要修改启动命令或者kill掉的命令
- 需要给[Makefile](../Makefile)添加一个服务，用于启动mortal
- 后端修改
  - 添加字段，用于存放牌谱分析数据JSON，以及什么时候分析的，是否有分析等。
  - 定时任务，定时检查没有分析数据的牌谱，进行分析，分析完之后添加到字段中。
  - 分析时，需要给每个人的每一打评分，分析完每一个人各自的牌
    - 即隐藏别人的牌谱、只显示其他人的牌河、吃碰等。
    - 需要详细到别人打出来，这张牌什么响应，自己摸牌，哪张牌最好。
    - 把全部的数据跑完后，评分体系以100分为准，q_values可能为[-xxx,xxx], 但以当前每一打的最低分为0分，当前每一打的最高分为100分, 舍去小数
      - 然后给每个人切牌、鸣牌等分数。
  - 给每个人的每一小局、大局进行评分，分数为平均分[0,100]
    - 这个评分体系可以通过后端修改。
  - 依据前端需要，添加合适的接口
    - 注意，只有对局详情可以展示每个人的详细对局评分数据
    - 批量接口时，只显示这个人的该大局的平均分数，以及每个小局的分数。

- 前端
  - 牌局复现器需要添加一个AI模式，将后端AI分析的数据结合到前端分析中。
    - 将每个步骤的分数展示出来，注意只展示当前选中的视角的角色。
    - 默认只显示前3个最佳分数的牌，以及当前自己打出去牌。
    - 而每一打的评分中，并不是0-100分的分数，应该按mortal_FAQ中的算法给出权重分数。
    - 额外有一个表格用于展示全部牌的分析数据及评分。
    - 牌局复现器中展示每个人每个小局的AI评分表。
    - 总评分表
  - 展示当前每个人的分数等级，需要给每个人的每个小局评分，即每一打的平均分，默认评分体系为：
    - AI: 99+
    - S+: 95+
    - S: 92.5+
    - S-: 90+
    - A+: 86.5+
    - A:  82+
    - A-: 79+
    - B+: 75+
    - B: 70+
    - B-: 65+
    - C+: 60+
    - C: 55+
    - C-: 50+
    - D: 40+
    - E: 35+
    - F: 10+
    - 不正打: 10-
  - 可在配置中修改AI评分体系。
  - 个人页面展示每一个对局本人的评分。
  - 线上牌谱统计中添加一个榜单，用于展示每个人每个小局的平均AI评分(以分数呈现)。
  - 对局表中展示每个人的对局评分。
