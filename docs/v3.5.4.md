## 联赛赛制修改
docs/v2/v2.0.0.md 时研发了联赛功能，联赛可能会存在不足16人的情况，一键创建赛程时。
- 需要考虑到不足16人，但大于12人的赛程配置。
- 小于12人的不配置。
- 陪打规则不变。

即保持积分赛+双败淘汰赛的核心思路不变，改动一下淘汰赛程

12～16人赛程双败淘汰赛赛制改动:
1. 积分赛，每个人8场半庄，依据积分分为前6位胜者组， 后面N个的都是败者组。
2. 淘汰赛第1阶段，两组内部每个人打4个半庄
- 胜者组后2进入败者组， 前4保留。
- 败者组前2晋级胜者组，败者组淘汰至只剩4个人(不包含胜者组退级的两个人)，即淘汰末尾的人，如果总人数刚好12人即不淘汰任何人。
3. 淘汰赛第2阶段，两组内部每个人打4个半庄，这个阶段胜者组和败者组都是6个人
- 胜者组前2晋级半决赛，其余4人进入淘汰赛第三阶段
- 败者组淘汰后2，其余4人进入淘汰赛第三阶段
4. 淘汰赛第三阶段，该阶段有8人，自由混打4个半庄，淘汰后2人，其余进入半决赛，即包含第二阶段保送的，一共8人晋级半决赛。
5. 半决赛，决赛和之前保持不变。


### 详细赛制

1. 积分赛结束分组
所有选手完成 8 个半庄后，按 PT 总积分排名：
| 排名    | 分组  |
| ----- | --- |
| 第1～6名 | 胜者组 |
| 第7名以后 | 败者组 |

2. 淘汰赛第一阶段
- 胜者组
| 名次 | 结果    |
| -- | ----- |
| 前4 | 保留胜者组 |
| 后2 | 降入败者组 |
- 败者组（N人）
| 名次 | 结果         |
| -- | ---------- |
| 前2 | 晋级胜者组      |
| 其余 | 按成绩保留至剩余4人 |

说明：
- 保留人数不包含胜者组降级的2人。
- 第一阶段结束后：
  - 胜者组固定为 6 人 
  - 败者组固定为 6 人
- 若总参赛人数为 12 人：
  - 原败者组仅有 6 人
  - 前2晋级胜者组后剩余4人
  - 不发生额外淘汰


3. 淘汰赛第二阶段
- 胜者组（6人）
| 名次 | 结果        |
| -- | --------- |
| 前2 | 直接晋级半决赛   |
| 后4 | 进入淘汰赛第三阶段 |
- 败者组（6人）
| 名次 | 结果        |
| -- | --------- |
| 前4 | 进入淘汰赛第三阶段 |
| 后2 | 淘汰        |


3. 第三阶段
- 不再区分胜者组、败者组
- 自由混打
- 每人进行 4 个半庄
| 名次 | 结果    |
| -- | ----- |
| 前6 | 晋级半决赛 |
| 后2 | 淘汰    |


- 第三阶段结束最终进入半决赛人数：
  - 第二阶段保送：2人
  - 第三阶段晋级：6人


| 阶段           | 人数变化    | 每人半庄数 | 晋级规则         |
| ------------ | ------- | ----- | ------------ |
| 积分赛          | 全体      | 8     | 前6胜者组，其余败者组  |
| 淘汰赛第一阶段（胜者组） | 6 → 4+2 | 4     | 前4保留，后2降级    |
| 淘汰赛第一阶段（败者组） | N → 2+4 | 4     | 前2升级，其余保留4人  |
| 淘汰赛第二阶段（胜者组） | 6 → 2+4 | 4     | 前2半决赛，后4第三阶段 |
| 淘汰赛第二阶段（败者组） | 6 → 4+2 | 4     | 前4第三阶段，后2淘汰  |
| 淘汰赛第三阶段      | 8 → 6+2 | 4     | 前6半决赛        |
| 半决赛          | 8 → 4   | 6     | 前4进入决赛       |
| 决赛           | 4 → 冠军  | 4     | 最终排名         |
