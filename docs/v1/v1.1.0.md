## 本期研发内容
1. 修改对局列表
   - 对局列表中过滤条件需要新增三麻、四麻的过滤选项，且所有选项使用下拉列表的方式过滤，进入列表默认为四麻+半桩的过滤条件。
2. 添加pt分机制，
   - 四麻 马点分以 +30 / +10 / -10 / -30 为准
   - 三麻 马点分以 +30 / 0 / -30 为准
3. 依据研发内容2的pt分机制， 为对局列表中添加pt分的显示。
4. 给每个玩家做统计图表
   - 显示一位率、二位率等
   - 最近对局排名曲线图
   - 显示玩家的总pt分
   - 特别注意！！！ 三麻、四麻、东风局、南风局都需要分开显示统计，因为是不同的场。
5. 添加pt排名
6. 可以给某个对局添加 役满、役满确定、役满机会的牌谱。
   - 同一局可添加多个牌谱
   - 添加时，需要有麻将的牌面点击，比如可选择多张牌。
   - 役种可参考： https://github.com/Diving-Fish/MajhongPointCal
   - 日麻牌面样式： https://github.com/lietxia/mahjong_graphic
     - 可以直接下载项目的资源： https://github.com/llx07/mahjong-vue/tree/main/src/assets
     - 注意其中H1m、H2p等是横摆牌
     - 0m,0p,0s是红五牌
   - 注意，需要对役种进行校验。
   - 需要可添加吃碰牌、手牌， 最后是胡牌张(役满确定和役满机会没有这张牌)
     - 碰牌可以选择横着的牌
     - 杠时可以选择怎么摆
7. 雀士管理中，需要可上传头像， 头像以base64的形式保存在数据库
8. 管理列表和普通列表明确分开，暂时注释掉线上对局的tab。
