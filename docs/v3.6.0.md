## 基于雀谜制作一个闯关小游戏
### 前提条件
1. 数据有版本号的概念，即前端可以展示哪些版本号的数据，前端可依据当前可支持的榜本号进行重放。
2. 数据存放于后端。
3. 单独有一个quemi-game的后端目录和前端目录，但是ui组件等还是可以复用原本的雀谜组件。
