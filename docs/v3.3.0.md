## 用户体系完善
- 用户字段修改
  - 用户新增email字段
  - 用户新增系统密码字段，且可由管理员手动重置某个人的系统密码，系统密码为随机的uuid
  - 用户近期登陆次数
  - 用户近期尝试登陆时间
  - 用户近期ip地址
- 用户登录次数限制
  - 5分钟内登陆失败5次，直接禁止登陆15分钟。
  - 注意重置登陆次数逻辑，正确即重置。 
- 添加用户登录日志，登录行为等。
- 管理员可强制重置某个人的密码，并生成系统密码，系统密码仅仅可作为无密码的用户登录。
- 使用系统密码登录后，用户需要自动跳转到重置密码的界面，并带上系统密码去重置。
  - 重置时需要用户输入email，并验证email
- 用户重置密码时，也需要给有email的才能重置，否则不允许重置。
  - 重置密码时，发送一封验证码邮件。
- 验证码体系
  - 单独一个表格，并且写明给哪个用户使用、用途、超时时间、验证码
  - 验证过之后，该验证码即失效。
  - 验证码为6为随机字母+数字
  - 验证码目前用于修改邮箱、重置密码、绑定邮箱
  - db_config.json中需要添加相关配置
  - 验证码需要以美化的HTML的形式，风格和网站一致，带上相关logo和设计。
  ```yaml
  emailConfig:
    smtpHost: "smtp.qq.com"
    smtpPort: 587
    from: "cubingpro@foxmail.com"
    fromName: cubingPro
    password: "xxxxx"
  ```

- [仅前端] 后端管理可表格化查看，不仅仅是卡片展示模式。
