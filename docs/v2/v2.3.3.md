## 问题修复
1. 联赛管理和联赛页面，没有正确显示人数和赛段
   - 联赛页面需要把已报名选手展示出来。
   - 赛段数也要正确展示出来。
     - 即使是0

2. 后端代码中，统计代码中，存在大量的单次查询处理，以及各类JOIN。
- 使用一次性的find代替批量查询。
  - 一次性查询全部的对局
  - 一次性查询全部的选手等
  - ...
- 如果没有必要，不要使用JOIN语法。
  - 通过两段find查询，在内存中进行数据的拼接

3. 前端中关于选手头像，需要做修复，目前查询出来都是空的，并且需要缓存起来。

4. 前端遇到500服务器错误，单独出一个服务器错误面板，并详细说明错误

5. 前端如果全局遇到了错误，不能白屏，而是正确定位错误，然后单独一个页面去详细说明错误。
