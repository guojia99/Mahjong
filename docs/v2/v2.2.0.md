## 研发
1. 统计栏目添加一个起手牌列表。
   - 即通过线上牌谱，获取某个选手的每个小局的起手牌，即起手的13张牌。
   - 线上对局已经有现成数据了。
2. 后端需要给每个起手牌打分,依据参考：
- 面子数比如123,345,456...
- 搭子比如23 45
  - 注意，显然45的搭子会比23好，因为45是中章
  - 而46的搭子比23差，因为46是坎搭子。
- 对子数比如11,33
- 刻子数比如111
- 场风、役牌、自风
- 赤宝牌比如0s、0p、0m等
- 本局宝牌比如宝牌指示牌为2s，则宝牌为3s，此时3s数需要可以加不少分
  - 而宝牌边，如2s、4s可以加一点分
  - 如宝牌连成了搭子，则加分会更多一些。
- 起手向听数
- todo 还有其他打分环节，需要你自己拓展。
  - 比如是否容易形成某种役牌

3. 分为两个tab
- 总起手牌列表
- 个人起手牌列表

4. 起手牌列表按照全部选手分页排序，排序以分数为准
5. 个人起手牌列表
- 用现成的麻将渲染工具，显示每一手的手牌
- 给出排序，按照分数
- 给出每个人的平均分
6. 做好前后端的接口交互。
