## 一、版本目标
- v2.0.0 版本将新增「联赛系统」。
- 联赛属于一种长期、多阶段、可配置的特殊赛事模式，支持：
  - 四麻半庄赛事
  - 线上对局
  - 线下对局录入
  - 多阶段赛制
  - 可配置晋级规则
  - 特殊马点规则
  - 自由约桌
  - 陪打机制
  - 联赛段位分统计
- 联赛中的每一个阶段，本质上都是一个“特殊房间”，用于承载该阶段对应的半庄对局。


## 二、联赛核心规则
### 1. 联赛基础限制
- 联赛仅支持：
  - 四麻
  - 半庄战

- 暂不支持：
  - 三麻
  - 东风战
### 2. 联赛生命周期
= 联赛生命周期如下：
```text
创建联赛
  ↓
报名阶段
  ↓
报名截止
  ↓
正式开赛
  ↓
阶段推进
  ↓
联赛结束
```

### 3. 报名机制
- 联赛必须先报名，再开赛。
- 规则：
  - 开赛前允许报名
  - 开赛后禁止新增参赛选手
  - 参赛名单固定
  - 联赛所有阶段均基于报名名单推进
- 报名添加雀魂UID
  - 需要选手有确定的UID
  - 没有UID时无法参加比赛。

## 三、联赛数据结构设计
### 1. 联赛基础信息
- 联赛表必须包含：
| 字段       | 说明              |
| -------- | --------------- |
| 联赛名称     | 联赛标题            |
| 联赛封面     | 可选              |

| 是否允许线下录入 | 是否支持线下成绩        |
| 创建人      | 管理员             |
| 参赛选手列表   | 报名名单            |

### 2. 联赛描述编辑器
- 联赛描述要求： 
  - 支持 Markdown
  - 支持图片粘贴
  - 图片自动转 Base64 存储
  - 支持富文本预览
- 适合：
  - 发布规则

  - 发布奖金

```text
  └── Stages

```
每个 Stage 均为独立配置。

## 四、赛段系统设计
### 1. 赛段特点
- 联赛赛段必须支持：
  - 灵活配置
  - 动态增删
  - 独立参数
  - 独立马点
  - 独立对局数
  - 独立晋级逻辑
### 2. 赛段可配置项
- 每个赛段至少包含：

| 字段       | 说明                   |
| -------- | -------------------- |
| 阶段名称     | 如：积分赛                |
| 阶段类型     | 积分赛 / 淘汰赛 / 半决赛 / 决赛 |
| 阶段状态     | 未开始 / 进行中 / 已结束      |
| 每人半庄数    | 默认对局数                |
| 马点配置     | 顺位马点                 |
| 是否允许陪打   | 是否允许已完成玩家陪打          |
| 是否允许自由约桌 | 是否自由创建牌桌             |
| 是否记录段位分  | 是否计入个人段位             |
| 是否锁定配置   | 开赛后锁定                |

### 3. 阶段锁定规则
- 阶段正式开启后,以下配置禁止修改：
  - 马点
  - 每人半庄数
  - 晋级规则
  - 阶段人数
  

但后续阶段仍可修改，示例：
```text
第一阶段开始后：
  第一阶段配置锁定

第二阶段尚未开始：
  第二阶段仍可编辑
```
### 4. 阶段启动机制
- 每个阶段必须：
  - 手动开启
  - 手动结束
  - 不自动推进
- 原因：
  - 需要人工确认成绩
  - 需要处理异常对局
  - 需要处理陪打情况
## 五、对局系统
### 1. 联赛对局
- 联赛中的每个半庄：
  - 与普通比赛逻辑一致
  - 使用同一套结算规则
  - 使用同一套牌谱系统
- 区别：
  - 对局归属于联赛阶段
  - 影响联赛积分
  - 可能影响晋级
### 2. 线上 / 线下支持
- 联赛支持：
  - 线上对局
    - 系统内直接创建房间
    - 管理员在线上房间上传联赛成绩
    - 注意这个特殊房间需要在联赛页面上传，且不在普通房间里面。
- 线下录入
  - 管理员手动录入：
      - 点数
      - 选手
      - 是否有陪打

### 3. 段位分记录
- 联赛对局可以： 
  - 计入个人段位

## 六、陪打机制
### 1. 陪打定义
当约桌人数不足时：
- 已经完成当前阶段的人，可以继续参与牌桌。
- 这些玩家称为： 陪打玩家
- 陪打玩家不会影响自身任何分数，即在联赛当前阶段中pt+0
  - 但是会影响自身的段位分和自身的统计
### 2. 陪打规则
陪打必须满足：
- 当前阶段已打满
- 当前阶段仍未结束
- 陪打每个对局只能有两个
### 3. 陪打展示
系统需要明确展示：
- 哪位玩家是陪打
- 哪场存在陪打
- 避免，正式成绩误解
- 避免，晋级统计错误
### 4. 陪打要求
即使为陪打：
- 仍需认真对局
- 不允许恶意放水





## 七、赛制设计

> 这里给出的半庄数为默认半庄数，均可修改



### 1. 积分赛阶段

规则 
- 所有人自由约桌
- 每人完成 8 个半庄
- 按最终 PT 排名
- 不淘汰任何人
- 陪打规则
打满 8 个半庄后：允许陪打。

### 2. 双败淘汰赛
- 总规则 
  依据实际人数划分： 胜者组 / 败者组
- 对局限制
- 胜者组只能与胜者组约桌。
- 败者组只能与败者组约桌。
- 陪打规则
  - 陪打允许跨组： 
  - 其他组已满半庄玩家 
  - 可参与陪打
  - 半庄数规则
    - 默认：每人 4 个半庄
    - 特殊保送除外。

### 八、淘汰赛阶段详细规则
#### 1. 淘汰赛第一阶段
- 胜者组

| 名次 | 结果        |
| -- | --------- |
| 前4 | 保送第三阶段胜者组 |
| 后4 | 原地保留      |

- 败者组

| 名次 | 结果        |
| -- | --------- |
| 前4 | 晋级第二阶段胜者组 |
| 其余 | 按成绩保留8人   |


#### 2. 淘汰赛第二阶段
- 胜者组

| 名次 | 结果      |
| -- | ------- |
| 前4 | 第三阶段胜者组 |
| 后4 | 第三阶段败者组 |



- 败者组

| 名次 | 结果      |
| -- | ------- |
| 前4 | 第三阶段败者组 |

#### 3. 淘汰赛第三阶段
- 胜者组

| 名次 | 结果      |
| -- | ------- |
| 前4 | 直接进入半决赛 |
| 后4 | 进入复活赛   |


- 败者组

| 名次 | 结果    |
| -- | ----- |
| 前4 | 进入复活赛 |
| 后4 | 直接淘汰  |



#### 4. 淘汰赛复活赛
- 规则
  - 剩余8人
  - 再进行4个半庄
  - 前4进入半决赛

### 九、半决赛设计
#### 1. 半决赛人数
- 淘汰赛结束后： 剩余 8 人。
#### 2. 随机编号
- 系统随机生成： A ～ H
#### 3. 对局组合
- 每次 2 个半庄：
  - A B C D
  - E F G H
  - A B E F
  - C D G H
  - A B G H
  - C D E F
- 生成后自动生成独立的半庄房间，确定哪几个人比这几个半庄。
- 录入线上对局时需要校验是否正确录入了线上确定的uid
#### 4. 半决赛特点
- 每位选手： 
  - 共进行 6 个半庄
  - 会与所有人相遇一次
#### 5. 结算规则
- 仅统计： 
  - 半决赛 12 个半庄 PT 
  - 不继承前阶段积分。

### 十、决赛设计
- 规则 
  - 半决赛前4进入 Final
  - 共进行4个半庄
  - 按最终 PT 排名
