## mortal多模型支持
1. mortal-server需要能支持多模型同时在线
- 即state_file配置为多个模型，service中可以起两个不同端口的进程。
- 这里可以简单一些，主要是能够通过多个config.toml配置启动两以上不同的服务。
- 端口号从9996、9995、9994等

2. 后端接入这里 mortal 配置修改为支持多个后端。
```json
[
    {
          "name": "mortal_v4",
          "version": "1",
          "url": "http://127.0.0.1:9996"
    },
    {
        "name": "mortal_v4",
        "version": "1",
        "url": "http://127.0.0.1:9996"
    }
]
```
3. 后端运行时，需要支持能保存多套模型的解析参数。
4. 如果数据有多套， 前端可以支持切换不同模型来查看。
5. 新增一个AI差异的功能，如果有多个模型的数据， 可以给出前端对比的差异值，即可以通过表格来对比两个模型对每一打的差异。
6. 候选手表格中`候选手	π	评分` 添加一列为 `πr(a|s)x100`, 你可以参考[mortal_FAQ.md](../mortal-server/mortal_FAQ.md) 的说明
