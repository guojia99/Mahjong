# 这是一个日本立麻将线下麻将计分的程序，第一期有如下功能

- 单帐号管理，仅需登录验证即可。
  - 但是需要预留未来可能的多帐号管理模式

- 雀士管理
  - 可以进行雀士管理，添加雀士
  - 雀士有头像、昵称、真实名字(非必要)
    - 需要能预留一些个人信息的字段(比如预留一个json)
  - 一个雀士可能有多个雀魂帐号，雀魂帐号一般是一个uid，需要有字段用于管理uid(uid一般也会跟着名字)

- 对局管理
  - 对局有两种，一种为线上，一种为线下
  - 线下对局先开启房间
    - 管理员可开启房间，和录入分数。
    - 房间关闭后，即可录入全部对局。
    - 可以快速添加已有雀士， 旁边有快捷创建雀士的入口。
    - 可以看到当前已经开启的房间列表。
    - 一个房间中的人不一定只能四个人，但是一个对局只能有4个人。
    - 一个房间里面可以有多个对局，可以按照原有人马快速开启下一个对局
    - 对局计分
      - 可以有负分，输入分数为整数
      - 4人分数总分为1000分(需要检查机制)
      - 3人分数总分为1050分
      - 对局未录分前，可以更换选手。
    - 其他字段有
      - 时间、地点(哪个雀桩-非必要)
        - 时间显示到分钟
      - 可额外记录是谁东起
      - 记录场次打的是: 东风局、半桩
  - 添加线上友人局
    - 线上对局获取数据参考项目: https://github.com/EvanMaFYH/majsoul-paipu
    - 添加对局时，自动获取到对局的雀士列表
      - 如果雀魂的uid已经和某个已有雀士绑定，则直接显示那个雀士
      - 如果没有，则需要手动选择一个雀士，并把uid添加到那个雀士上。
    - 对局分数记录结构和线下局一致，用额外的字段来管理是否为雀魂对局,以及保存导入连接。
    
- 项目更新记录
