## AI牌谱分析和复盘器优化
1. 美化牌谱评分总览，S为红色、A为橙色..., 表格每行行高大一些， 名字行需要展示头像。
2. “Mortal AI 复盘” 自带一个切换器。
   - 可切换到上/下一个观察者的决策点。
   - 可切换到上/下一个差异点(即自己打的和AI打的有差别的地方) (100%一致时置灰)
3. 最上方显示
```text
**信导的粉丝** 大局: 95 (S+)
```
需要修改为
```text
**信导的粉丝**: 95 (S+) ｜ 87(A+)
```
来区分显示本局和大局

4. 复盘器中，东南西北的字体显示再大一些。本场 · 立直棒 的显示也大一些。
5. Bug 复盘器牌河中:
- 左家: 牌面需要旋转180度展示，其他不需要变
- 对家和本家: 第二排、第三排的顺序反了, 应该这样:
  - 对家：
    - 第三排 
    - 第二排
    - 第一排

    - 第一排
