## v2.0.0 — 2026-05-09

- 新增「联赛系统」：完整重构，支持多阶段竞技赛事
- 联赛后台拆分为系列 / 赛季 / 赛季详情 / 选手管理 / 赛段管理 / 单赛段管理多个独立页面
- 「一键创建标准赛制」：积分赛 → 三阶段双败淘汰 → 复活赛 → 半决赛 → 决赛
- 实现严格的双败淘汰晋级算法（胜者组 / 败者组 / 复活机制）
- 报名期间所有内容（赛段配置、顺序、选手）均可自由修改，开赛后自动锁定
- 重构选手报名流程，支持批量报名、种子分配 (A、B、C…)
- 半决赛按种子顺序自动生成 3 轮 × 2 桌对阵
- 修复 PT 重算累积错误、晋级规则同步等多项 bug
- 联赛阶段公开页适配新模型（含晋级标记、对局分数实时同步）
- 联赛对局录入：管理后台支持「线上录入」和「线下录入」两种方式
- 线上录入：粘贴雀魂牌谱链接，按 UID 自动识别本赛段选手并创建对局，无需手动选人
- 线下录入：选定 4 名选手即可创建对局，可选直接录入终局分数
