# 更新日志

## v1.6.2 — 2026-05-09

- 侧边栏按「对局 / 排行 / 统计 / 工具 / 管理」分组，含子项的分组默认收起
- PC 端侧边栏高度固定为视口高度，不再随右侧内容滚动而拉伸
- 优化移动端抽屉与桌面端布局的适配体验

## v1.6.1 — 2026-05-09

- 新增「更新日志」页面，每个版本以独立卡片形式展示
- 支持简体中文 / 繁體中文 / English / 日本語 切换浏览

## v1.6.0 — 2026-05-06

- 新增「日麻规则」页面，包含规则总览 / 名词释义 / 役种表 / 符数表 / 点数表 五个 Tab
- 规则页支持可收起的目录导航，文中可内嵌渲染麻将牌

## v1.5.3 — 2026-05-05

- 已录分对局支持修改场局类型（半庄 / 东风），保存后自动重算 PT
- 前端默认按半庄优先展示
- 线下场次输入「东风」需二次确认；未指定东起时默认第一位选手东起

## v1.5.2 — 2026-04-29

- 趣味排行新增场均立直率、场均点炮率、场均自摸率、场均和率

## v1.5.1 — 2026-04-29

- 新增线上对局牌谱详情弹窗：每局得失分、立直 / 点炮 / 自摸 / 最高打点等汇总信息
- 仅线上对局可查看牌谱详情

## v1.5.0 — 2026-04-28

- 全站国际化：支持简体中文 / 繁體中文 / English / 日本語，默认简体中文
- 顶栏新增 GitHub 链接图标

## v1.4.4 — 2026-04-27

- 线上对局新增开始时间 / 结束时间显示
- 后台新增「一键重新获取线上牌谱信息」按钮，附带进度条与勾选项

## v1.4.3 — 2026-04-27

- 房间关闭后，对局仍可删除 / 修改但不可新增
- 对局支持单独录入开始 / 结束时间；排序优先级：对局时间 > 房间时间 > 录入时间
- 已关闭且无对局的房间可被删除

## v1.4.2 — 2026-04-27

- 新增「天梯排位」段位与马点系统（仅四麻半庄计入）
- 排位分支持后台配置；马点 / 段位修改后自动重算全局成绩
- 主页新增段位一览表与马点配置展示

## v1.4.1 — 2026-04-27

- 雀士详情页位率新增四位率，默认四麻半庄视角
- 顺位曲线改为折线图；新增 PT 累计曲线
- 支持选择最近 10 / 20 / 50 / 100 局；统计可区分线上 / 线下

## v1.4.0 — 2026-04-27

- 重新引入线上对局：通过雀魂牌谱链接导入

- 役满列表支持类型筛选与背景色区分（役满 / 役满确定 / 役满机会）
