# 日麻符計算

## 符の基礎

符（ふ）は日麻の和了時の基本点の単位で、翻数とともに最終的な得点を決定します。

## 符計算ルール

### 基本符

和了時の基本符は **20符** です。

### 雀頭の加符

| 雀頭の種類 | 加符 |
|-----------|------|
| 非役牌の雀頭 | +0符 |
| 自風牌の雀頭 | +2符 |
| 場風牌の雀頭 | +2符 |
| 三元牌（白/發/中）の雀頭 | +2符 |
| **連風雀頭**（自風=場風） | +4符（一部ルールでは+2符） |

### 面子の符数

| 面子の種類 | 明刻（鳴牌） | 暗刻（手牌） | 明カン | 暗カン |
|-----------|------------|------------|--------|--------|
| 幺九牌（字牌/19m/p/s） | +4符 | +8符 | +16符 | +32符 |
| 中張牌（2〜8） | +2符 | +4符 | +8符 | +16符 |

### 順子

順子は明暗を問わず**加符なし**（+0符）。

### 和了方法の加符

| 和了方法 | 加符 |
|---------|------|
| ロン | +10符 |
| ツモ | +2符 |
| 平和ツモ | +0符（平和のメンゼンツモ時はツモの2符を加算しない） |
| 辺張待ち（12mや89mなど） | +2符 |
| 嵌張待ち（間の1枚待ち） | +2符 |
| 単騎待ち（雀頭待ち） | +2符 |

> **注意**：平和型のロン両面待ちの場合、符数は固定で30符（基本20 + ロン10）となります。

### 七対子

七対子の符数は**固定25符**で、上記ルールには従いません。

## 符計算の例

### 例1：基本型（30符）

{{[mahjong] hand:2m3m4m5p6p7p8s9s1s2s3s4s}}

- 基本符：20
- 順子 ×4：0
- 雀頭（非役牌）：0
- 両面待ち：0
- ロン：+10
- **合計：30符**

### 例2：暗刻あり（50符）

{{[mahjong] hand:3m3m3m5p6p7p8s8s9s9s1z1z2z}}

- 基本符：20
- 中張暗刻 3m：+4
- 順子 5p6p7p：0
- 中張暗刻 8s：+4
- 幺九暗刻 9s：+8
- 順子 1s2s3s：0
- 雀頭 1z：+2（自風または場風）
- 嵌張待ち 2z：+2
- ツモ：+2
- **合計：42 → 切り上げ 50符**

### 例3：字牌暗刻あり（50符）

{{[mahjong] hand:7z7z7z3m4m5m1p1p1p2s3s4s5z5z6z}}

- 基本符：20
- 三元牌暗刻 7z：+8
- 順子 3m4m5m：0
- 中張暗刻 1p：+4
- 順子 2s3s4s：0
- 雀頭 5z：+0
- 両面待ち 6z：0
- ロン：+10
- **合計：42 → 切り上げ 50符**

## 符の切り上げ

符計算の結果が10の倍数でない場合、**最も近い10に切り上げ**ます：

- 20 → 20
- 21〜30 → 30
- 31〜40 → 40
- 41〜50 → 50
- 51〜60 → 60
- 61〜70 → 70
- 71〜80 → 80
- 81〜90 → 90
- 91〜100 → 100
- 101〜110 → 110

## 符数一覧表

| 符数 | 説明 |
|------|------|
| 20 | 基本値（七対子は25） |
| 25 | 七対子専用 |
| 30 | 最も一般的な符数（ロン基本） |
| 40 | 中張刻子または暗刻を含む場合 |
| 50 | 暗刻+特殊待ちを含む場合 |
| 60 | 複数の暗刻を含む場合 |
| 70 | 字牌刻子+他の加符を含む場合 |
| 80 | 暗カンを含む場合 |
| 90+ | 極端な場合（複数暗カン+字牌） |
| 100〜110 | 理論上の最大値 |

## 符数と基本点の対応

基本点 = 符 × 2^(翻+2)

例：30符3翻 = 30 × 2^5 = 960

基本点が2000を超えると満貫体系に入ります（点数表参照）。
