# 面子（めんつ）

**分類**：基本用語

面子（めんつ）とは、和了牌型を構成する基本の組み合わせ単位です。面子は三種類に分かれます：

## 順子（じゅんつ）

同スートの連続した3枚の数牌の組み合わせ。

例：{{[mahjong] chi:2m3m4m}}、{{[mahjong] chi:5p6p7p}}、{{[mahjong] chi:1s2s3s}}

- 数牌のみで構成可能（字牌は順子にならない）
- 同スートで連続している必要がある
- スートを跨ぐことはできない

## 刻子（こうつ）

同じ牌3枚の組み合わせ。

例：{{[mahjong] pon:5z5z5z}}、{{[mahjong] pon:3m3m3m}}、{{[mahjong] pon:9p9p9p}}

- どの牌でも刻子を構成できる
- **明刻**：他家の捨て牌をポンして構成
- **暗刻**：手牌の中で自然に揃った同じ牌3枚

## カンツ（槓子）

同じ牌4枚の組み合わせ（刻子の拡張）。

- **明カン**：ポン後に他家が4枚目を捨てた時、または手牌に3枚あり他家が4枚目を捨てた時
- **暗カン**：手牌に同じ牌4枚があり、自ら暗カンを宣言
- **加カン**：既にポンした刻子に、自分で4枚目を摸った後加カン
- カン後は王牌から1枚補摸（嶺上牌）し、カンドラ表示牌が1つ増加

### 符数の違い

| 面子 | 中張牌 | 幺九牌 |
|------|--------|--------|
| 順子 | 0符 | 0符 |
| 明刻 | +2符 | +4符 |
| 暗刻 | +4符 | +8符 |
| 明カン | +8符 | +16符 |
| 暗カン | +16符 | +32符 |
