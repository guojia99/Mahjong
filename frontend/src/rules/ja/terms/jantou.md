# 雀頭（じゃんとう）

**分類**：基本用語

雀頭（じゃんとう）とは、同じ牌2枚で構成される対子で、和了牌型において面子とともに使用されます。

## 和了牌型における役割

標準牌型（4面子+1雀頭）において、雀頭は不可欠な一部です：

- 4組の面子 + 1組の雀頭 = 3×4 + 2 = **14枚**
- 雀頭は刻子の「不完全版」とも言える

## 雀頭の符数加算

| 雀頭の種類 | 加符 |
|-----------|------|
| 非役牌 | +0符 |
| 自風牌 | +2符 |
| 場風牌 | +2符 |
| 三元牌（白/發/中） | +2符 |
| 連風（自風 = 場風） | +4符 |

## 特殊な場合

- **単騎待ち**：雀頭の牌だけを待つ状態（既に4面子揃い、雀頭の2枚目が不足）
- **七対子**：7組の雀頭で構成される特殊牌型
- **国士無双**：13種の幺九牌のいずれか1枚を待つ13面待ち
