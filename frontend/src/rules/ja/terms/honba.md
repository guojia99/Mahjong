# 本場と連荘

**分類**：基本用語

## 本場（ほんば）

本場とは、親が同じ局に留まった回数です。連荘するたびに本場数が+1されます。

- 東一局一本場 → 親連荘 → 東一局二本場 → ...
- 本場が0の時は通常省略される（東一局 = 東一局零本場）

### 本場と点数

本場が1増えるごとに、和了点数は以下のように増加します：

| 方法 | 加算 |
|------|------|
| 親のツモ | 各人 +100 |
| 親のロン | +300 |
| 子のツモ | 子各+100、親+200 |
| 子のロン | +300 |

## 連荘（れんちゃん）

親が連荘（同じ局に留まる）する条件：

1. **親が和了**（ツモおよびロン含む）
2. **流局時に親が聴牌**（荒牌聴牌連荘）
3. **九種九牌流局**
4. **四風連打流局**
5. **四カンツ流了**（一部ルール）

### 連荘の表示

- 連荘時は本場棒（本場を示す100点棒）が増加
- 連荘は場風のローテーションに影響しない
- 本場棒は誰かが和了した時に回収される

## 連荘が対局進行に与える影響

- 連荘は対局時間を延長する
- 高本場時は点数が著しく増加し、リスクとリターンともに大きくなる
- 連荘が多いことは通常、親の運が良いか技術が高いことを示す
