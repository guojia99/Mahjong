# 聴牌（てんぱい）

**分類**：基本用語

聴牌（てんぱい）とは、手牌があと1枚特定の牌を得るだけで和了できる状態のことです。

## 待ちの種類

### 両面待ち（りゃんめん）

連続した2枚のうちどちらかを待つ。

例：手牌に {{[mahjong] hand:3m4m}} があり、2m または 5m を待つ

### 嵌張待ち（かんchan）

2枚の間に1枚挟まれた形で待つ。

例：手牌に {{[mahjong] hand:3m5m}} があり、4m を待つ

### 辺張待ち（ぺんchan）

数牌の列の端の牌を待つ。

例：手牌に {{[mahjong] hand:1m2m}} があり、3m を待つ（0mは待てない）

### 単騎待ち（たんき）

雀頭を構成する牌1枚だけを待つ。

例：既に4面子揃っており、手牌に {{[mahjong] hand:5z}} があり、もう1枚の 5z を待つ

### シャンポン待ち

2種類の異なる牌を同時に待ち、どちらかで雀頭を構成する。

### 多面待ち

3種類以上の牌を待つ形。三面待ち、四面待ちなど。

## 待ちと符数

待ちの形は符数に影響します：

| 待ちの形 | 加符 |
|---------|------|
| 両面待ち | +0符 |
| 嵌張待ち | +2符 |
| 辺張待ち | +2符 |
| 単騎待ち | +2符 |
| シャンポン待ち | +0符 |

## 流局時の聴牌

荒牌流局時、聴牌を宣言したプレイヤーは不聴のプレイヤーから不聴罰符を徴収できます。
