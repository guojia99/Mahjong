# 門前（メンゼン）

**分類**：基本用語

門前（メンゼン、正式には門前清）とは、手牌が副露（チー、ポン、明カン）を行っていない状態のことです。

## 門前と鳴牌

| 操作 | 門前か？ |
|------|---------|
| 副露なし | 門前 |
| チー | 非門前 |
| ポン | 非門前 |
| 明カン | 非門前 |
| 暗カン | **門前** |

暗カンは門前状態を維持します。

## 門前限定役

以下の役は門前状態でのみ成立します：

| 役名 | 翻数 |
|------|------|
| リーチ | 1翻 |
| ダブルリーチ | 2翻 |
| イッパツ | 1翻 |
| 門前清自摸和 | 1翻 |
| 平和 | 1翻 |
| 一盃口 | 1翻 |
| 七対子 | 2翻 |
| 国士無双 | 役満 |
| 九蓮宝燈 | 役満 |
| 四暗刻 | 役満 |
| 清一色（門前） | 6翻 |

## 門前の価値

門前は日麻戦略の核心概念の一つです：

1. 門前限定役が多くの追加翻数を提供する
2. リーチは門前状態でのみ宣言可能
3. 門前ツモ和了自体が1翻の役
4. 平和は達成しやすい1翻（門前ロン+両面待ち+非役牌雀頭）
