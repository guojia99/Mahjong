# 場風と自風

**分類**：基本用語

## 場風（ばかぜ）

場風とは、現在の対局がどの風圏の段階にあるかを示します：

| 風圏 | 対応 |
|------|------|
| 東場 | 東一局〜東四局 |
| 南場 | 南一局〜南四局 |
| 西場（延長戦） | 西一局〜西四局 |

- 東風戦は東場のみ
- 半荘戦は東場と南場
- 場風はその風圏の役牌を決定する

## 自風（じかぜ）

自風とは、各プレイヤーがその局で持つ風位のことです：

| 位置 | 自風 |
|------|------|
| 東家 | 東 |
| 南家 | 南 |
| 西家 | 西 |
| 北家 | 北 |

- 毎局の開始時、親は東家
- 親が交代すると、各家の自風もローテーションする

## 役牌

自分の自風または場風と手牌の刻子/カンツが一致した場合、役牌役が成立します：

| 状況 | 役名 | 翻数 |
|------|------|------|
| 自風刻子 | 自風牌 | 1翻 |
| 場風刻子 | 場風牌 | 1翻 |
| 連風刻子（自風=場風） | 連風牌 | 2翻（一部ルールでは1翻+1翻） |

## 親と子

- **親（東家）**：その局の親で、常に東家の位置に座る
- **子（西家、南家、北家）**：残り3家
- 親が和了すると親が連荘（本場+1）、子が和了すると親が交代
