# 日本麻雀ルール概要

## 基本情報

日本麻雀（日麻、リーチ麻雀）は四人麻雀の一種で、「リーチ」ルールを最大の特徴としています。本ページでは日麻の基本ルールの枠組みを解説します。詳細は各サブページを参照してください。

- **ゲームの目的**：終局時に得点が最も多いプレイヤーが勝者
- **配給原点**：各自が初期に25000点または30000点を所持（プレイヤー間の話し合いで決定）、一般的に25000点

## 牌

136枚の牌を使用します（花牌なし）。

- **数牌（シュンパイ）**：万子（1m〜9m）、筒子（1p〜9p）、索子（1s〜9s）、各4枚で計108枚
- **字牌（ジハイ）**：風牌（東南西北）+ 三元牌（白發中）、各4枚で計28枚
- **赤宝牌（赤ドラ）**：赤五万、赤五筒、赤五索各1枚、対応する通常の五牌と差し替え

## 対局の長さ

日麻は「半荘」を標準的な1ラウンドの単位とし、以下の変体もあります：

| タイプ | 説明 |
|--------|------|
| **東風戦** | 東場のみ（最少4局）、短時間で終わる、比較的よく見られる |
| **半荘戦** | 東場 + 南場（最少8局）、最も主流のルール |
| **一荘戦** | 東場 + 南場 + 西場 + 北場、大会などで比較的よく見られる |
| **东北戦** | 東場 + 北場、東北地方や北海道で比較的よく見られる |
| **東々戦** | 東場を2周、東一局から東八局まで |

## プレイヤーと座席

- 毎局1名が**親**（東家）、残り3名が**子**
- 東家から反時計回りに南家、西家、北家
- 自分の左側を**上家**、右側を**下家**、正面を**対家**と呼ぶ
- 自分以外のプレイヤーを総称して**他家**と呼ぶ

### 起家の決定

1. 東南西北の4枚の牌を裏返して混ぜ、各人が1枚引く
2. 東を引いた人が自分の席を選び、南西北は反時計回りに順次着席
3. 東位の人は2つのサイコロを振り、東位から反時計回りにその目を数え、その人が臨時親
4. 臨時親がさらに2つのサイコロを振り、その位置から反時計回りに目を数え、その人が起家（正式な親）

## 対局の流れ

### 配牌

- 洗牌後、牌山を積み、親が14枚、子が13枚取る
- 残りの牌で「山」を構成：各自の前に17幢（34枚）、最後の7幢が**王牌**

### 摸打

- 親が14枚から1枚捨てるところから始まり、反時計回りに交代
- 各ターン：牌山の末端から**摸牌** → 自分の河に1枚**打牌**
- 摸牌後は鳴牌（副露）または打牌が可能

### 流局と続行

- 山牌が尽きても誰も和了しない場合は**流局**（荒牌）
- 流局時に聴牌者と不聴者がいる場合、**ノーテン罰符**の精算を行う
- 特定条件を満たすと次の局へ（連荘ルール参照）

### 親権の交代（連荘と輪荘）

- **連荘**：親が和了すると引き続き次局も親を担当し、本場 +1（東一局1本場など）
- **輪荘**：子が和了すると、現在の親の次家が次局の親となり、次の局名へ進む
- **流局連荘**：流局時に親が聴牌の場合、親は連荘（聴牌連荘ルール）；一部ルールでは和了のみ連荘（和了連荘）
- 局名の順序：東一局 → 東二局 → 東三局 → 東四局 → 南一局 → ... → 南四局終了

## 和了条件

和了には以下の条件をすべて満たす必要があります：

1. **牌型成立**：手牌（副露含む）が和了牌型に合致する
2. **最低1翻**：少なくとも一つの有効な役（翻数 ≥ 1）を持つ
3. **特殊制限**：役なしでは和了できない（一翻縛り）

> 和了は**強制ではない**。和了できる場合でも和了しない（ツモ/ロンを宣言しない）ことを選択でき、摸打は継続される。これは自分に関係のない他家のリーチ時には特に重要。

## 和了牌型

### 基本牌型（4面子+1雀頭）

4組の面子（順子または刻子）と1組の雀頭（対子）で構成、計14枚。

### 七対子

7組の異なる対子、計14枚。符数は固定25符。

### 国士無双（特殊牌型）

{{[mahjong] hand:1m9m1p9p1s9s1z2z3z4z5z6z7z}}

13種類の幺九牌各1枚 + そのうち任意の1枚を重ね、計14枚。

## 鳴牌（副露）

### チー

- 上家（左方）の捨て牌のみチー可能
- **順子**（同スートの連続した3枚）を構成する
- チー後は手牌から1枚を捨てる

### ポン

- 任意の家の捨て牌をポン可能
- **刻子**（同じ牌3枚）を構成する
- ポン後は手牌から1枚を捨てる

### カン

- **明カン**：手牌に刻子があり、他家が4枚目を捨てた時にカン
- **暗カン**：手牌に同じ牌4枚があり、暗カンを宣言（門前を維持）
- **加カン**：既にポンした刻子に、自分で4枚目を摸った時に加カン
- カン後は王牌から1枚補摸（嶺上牌）、カンドラが1つ増加

## リーチ

### リーチ宣言

- 門前状態（副露なし）で、手牌が聴牌時に「リーチ」を宣言可能
- リーチには **1000点**のリーチ棒を支払う
- リーチ後は手牌を入れ替え不可（摸切またはツモ和了のみ）

### リーチ関連役

| 役名 | 翻数 | 条件 |
|------|------|------|
| リーチ | 1翻 | リーチ宣言後に和了 |
| ダブルリーチ | 2翻 | 第1巡でリーチ宣言 |
| イッパツ | 1翻 | リーチ後、次の鳴牌前にツモ和了 |

## 特殊和了

| 役名 | 翻数 | 条件 |
|------|------|------|
| 天和 | 役満 | 親の配牌時点で和了 |
| 地和 | 役満 | 子が第1ツモで和了（第1巡に鳴牌なし） |
| 海底摸月 | 1翻 | 山牌の最後の1枚を摸いて和了 |
| 河底撈魚 | 1翻 | 山牌の最後の1枚を摸いた後の捨て牌をロン |
| 嶺上開花 | 1翻 | カン後の嶺上牌で和了 |
| 槍槓 | 1翻 | 他家の加カンの牌をロン |
| 人和 | 役満 | 子が配牌後、第1巡内に他家の捨て牌をロン（古役、事前の取り決めが必要） |

## 点数体系

日麻の点数は**翻**と**符**によって決定されます：

- **翻**：所持する役種の合計
- **符**：牌型、和了方法などで決まる基本点
- 点数計算式：基本点 = 符 × 2^(翻+2)

### 満貫体系

| 条件 | 名称 | 子のロン | 親のロン | 子のツモ(子/親) | 親のツモ |
|------|------|----------|----------|-----------------|----------|
| 3翻70符 / 4翻40符 / 5翻 | 満貫 | 8000 | 12000 | 2000/4000 | 4000all |
| 6〜7翻 | 跳満 | 12000 | 18000 | 3000/6000 | 6000all |
| 8〜10翻 | 倍満 | 16000 | 24000 | 4000/8000 | 8000all |
| 11〜12翻 | 三倍満 | 24000 | 36000 | 6000/12000 | 12000all |
| 13翻以上 | 累計役満 | 32000 | 48000 | 8000/16000 | 16000all |
| 特定牌型 | 役満 | 32000 | 48000 | 8000/16000 | 16000all |
| 特定牌型 | ダブル役満 | 64000 | 96000 | 16000/32000 | 32000all |

> 親のツモは各家同額。

### 点数計算式

- 基本点 = 符 × 2^(翻+2)
- 子のロン = 基本点 × 4
- 親のロン = 基本点 × 6
- 子のツモ = 子各が基本点、親が基本点 × 2 を支払う
- 親のツモ = 各人が基本点 × 2 を支払う

## 本場棒とリーチ棒

- **本場**：連荘時に本場 +1、本場が1増えるごとに基本点×300（ロン）または各人×100 / 親×200（ツモ）を加算
- **リーチ棒**：リーチ時に場に出す1000点の点棒、その局の和了者が全額回収

## 責任払い（包牌）

ある家の鳴牌が他家の特定役満の成立を不可避にする場合、その鳴牌者が全額点数を負担する（責任払い）：

- **大三元包**：3種類目の三元牌をポンした人が大三元の責任払い
- **大四喜包**：4種類目の風牌をポンした人が大四喜の責任払い
- **四カンツ包**：4組目のカンをした人が四カンツの責任払い
- **大三元包**は大三元完成時に、3枚目の三元牌をポンした人が全額支払う

## 同時和了（頭跳ね・二家和・三家和）

同一巡で複数の家が同一の捨て牌を同時にロンした場合の処理：

| ルール | 説明 |
|--------|------|
| **頭跳ね**（最も一般的） | 放銃者から反時計回りで最も近いプレイヤーのみ和了 |
| **二家和** | 両方和了、放銃者がそれぞれに支払う |
| **三家和** | 三家すべて和了、または直接流局 |

## 流局ルール

### 荒牌（通常流局）

- 山牌が尽きても誰も和了しない
- 聴牌者と不聴者がいる場合は**ノーテン罰符**の精算を行う

### ノーテン罰符

| 状況 | 不聴者1人あたりの支払 |
|------|----------------------|
| 1人聴牌 / 3人不聴 | 1000 |
| 2人聴牌 / 2人不聴 | 1500 |
| 3人聴牌 / 1人不聴 | 3000 |
| 4人聴牌 / 0人不聴 | 支払わない |

> 各不聴プレイヤーは各聴牌プレイヤーに同額を支払う。親家・子家の区別はない。

### 途中流局

| タイプ | 条件 |
|--------|------|
| **九種九牌** | 配牌時に手牌に9種類以上の幺九牌が含まれる場合、流局を宣言でき、親は連荘 |
| **四風連打** | 第1巡で4家全員が各自の風牌を捨てる（東が東、南が南…）、流局を宣言できる |
| **四カンツ散了** | 一局中に4組のカンが成立した時（一部ルールでは流局しない） |
| **三家和流局** | 同一巡で3家が同時に和了した場合、直接流局 |

### 流局満貫

- 流局時にリーチを宣言済みで手牌が聴牌状態の家がいる場合、不聴プレイヤーから満貫点数を徴収できる
- 採用の有無や処理方法は事前の取り決めが必要

## ゲームの終了と精算

### 半荘の終了条件

- 南四局終了後に親が輪荘（子が和了または親が不聴で流局）、半荘終了
- **あがりやめルール**：南四局で親が和了後、既に1位の場合、連荘するかどうかを自行選択できる

## ハコ（トビ）

- 「ハコ（トビ）」ルール採用時、半荘途中にプレイヤーの点数が0以下になった場合、ゲームは即終了
- 採用しない場合、マイナス点数のプレイヤーは他のプレイヤーから点棒を借りて継続

### 延長戦

| タイプ | 条件 |
|--------|------|
| **西入** | 南場終了時に誰も点数が30000（または33300）に到達していない場合、西場へ |
| **北入** | 西四局後も条件を満たさない場合、北場へ |
| **西入即終了** | 西場に入った後、誰かが条件を満たした時点で即終了（ネット麻雀でよく使用） |

### 精算ルール

ゲーム終了後、順位に応じて点数の調整を行う（採用の有無は事前の取り決めが必要）：

| ルール | 説明 |
|--------|------|
| **馬（ウマ）** | 4位が1位に、3位が2位に支払う（一般的：+15/-5/+5/-15 または +20/-10/+10/-20） |
| **丘（オカ）** | 最終得点1位が追加報酬を獲得、差額は配給原点と原点の合計から差し引く |

## 事前の取り決めが必要な細則

以下のルールは地域や団体によって異なり、ゲーム開始前に明確にする必要があります：

### アリアリ / ナシナシ

| ルール | 説明 |
|--------|------|
| **アリアリ** | 後付（聴牌時に役が未確定）と食い断（副露ありの断幺九）を認める、関東地方が主流 |
| **ナシナシ** | 後付と食い断を認めない（完全先付）、関西地方が比較的伝統的 |

### その他の細則オプション

| 項目 | オプション |
|------|-----------|
| 連風雀頭 | 2符とするか4符とするか |
| 七対子 | 25符2翻または50符1翻 |
| 嶺上開花・海底摸月 | ツモ2符を加算するかどうか |
| ツモ平和 | 認める（ツモピン）か認めないか |
| 累計役満 | 採用するかどうか |
| ダブル役満 | 採用するかどうか、どれをダブルとするか |
| 喫換 | 不可 / 同筋不可 / 可 |
| 二翻縛り | 採用しない / 4本場以降採用（親は二翻以上確定が必要） |
