# Menzen (Closed Hand)

**Category**: Basic Terms

Menzen (also called Menzenchin) refers to the state where your hand has not had any open melds declared (Chi, Pon, Minkan).

## Menzen and Melds

| Action | Menzen? |
|--------|---------|
| No melds declared | Menzen |
| Chi | Not menzen |
| Pon | Not menzen |
| Minkan (Open Kan) | Not menzen |
| Ankan (Concealed Kan) | **Menzen** |

Ankan does not break the menzen state.

## Menzen-Only Yaku

The following yaku can only be achieved in menzen state:

| Yaku | Han |
|------|-----|
| Riichi | 1 Han |
| Double Riichi | 2 Han |
| Ippatsu | 1 Han |
| Menzen Tsumo | 1 Han |
| Pinfu | 1 Han |
| Iipekou | 1 Han |
| Chiitoitsu | 2 Han |
| Kokushi Musou | Yakuman |
| Chuuren Poutou | Yakuman |
| Suuankou | Yakuman |
| Chin'iisou (Menzen) | 6 Han |

## Value of Menzen

Menzen is one of the core strategic concepts in Japanese Mahjong because:

1. Menzen-only yaku provide significant extra han
2. Riichi can only be declared in menzen state
3. Menzen Tsumo is itself a 1 Han yaku
4. Pinfu is an easily achievable 1 Han yaku (menzen ron + ryanmen wait + non-yaku pair)
