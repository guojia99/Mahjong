# 日麻符數表

## 符數基礎

符（ふ）是日麻和牌時的基礎點數單位，與番數共同決定最終得點。

## 符數計算規則

### 基礎符數

和牌時基礎符數為 **20 符**。

### 雀頭加符

| 雀頭類型 | 加符 |
|----------|------|
| 非役牌雀頭 | +0 符 |
| 自風牌雀頭 | +2 符 |
| 場風牌雀頭 | +2 符 |
| 三元牌（白/發/中）雀頭 | +2 符 |
| **連風雀頭**（自風=場風） | +4 符（部分規則為 +2 符） |

### 面子符數

| 面子類型 | 明刻（鳴牌） | 暗刻（手牌） | 明槓 | 暗槓 |
|----------|-------------|-------------|------|------|
| 幺九牌（字牌/19m/p/s） | +4 符 | +8 符 | +16 符 | +32 符 |
| 中張牌（2-8） | +2 符 | +4 符 | +8 符 | +16 符 |

### 順子

順子**不加符**（+0 符），無論明暗。

### 和牌方式加符

| 和牌方式 | 加符 |
|----------|------|
| 榮和（ロン） | +10 符 |
| 自摸（ツモ） | +2 符 |
| 平和自摸 | +0 符（平和門清自摸時不加自摸 2 符） |
| 邊張聽牌（待 12m 或 89m 等） | +2 符 |
| 嵌張聽牌（待中間一張） | +2 符 |
| 單騎聽牌（待雀頭） | +2 符 |

> **注意**：平和型榮和兩面聽時符數固定為 30 符（基礎20 + 榮和10）。

### 七對子

七對子的符數**固定為 25 符**，不按上述規則計算。

## 符數計算示例

### 示例 1：基本型（30符）

{{[mahjong] hand:2m3m4m5p6p7p8s9s1s2s3s4s}}

- 基礎符：20
- 順子 ×4：0
- 雀頭（非役牌）：0
- 兩面聽牌：0
- 榮和：+10
- **合計：30 符**

### 示例 2：含暗刻（50符）

{{[mahjong] hand:3m3m3m5p6p7p8s8s9s9s1z1z2z}}

- 基礎符：20
- 中張暗刻 3m：+4
- 順子 5p6p7p：0
- 中張暗刻 8s：+4
- 幺九暗刻 9s：+8
- 順子 1s2s3s：0
- 雀頭 1z：+2（自風或場風）
- 嵌張聽 2z：+2
- 自摸：+2
- **合計：42 → 切上 50 符**

### 示例 3：含字牌暗刻（70符）

{{[mahjong] hand:7z7z7z3m4m5m1p1p1p2s3s4s5z5z6z}}

- 基礎符：20
- 三元牌暗刻 7z：+8
- 順子 3m4m5m：0
- 中張暗刻 1p：+4
- 順子 2s3s4s：0
- 雀頭 5z：+0
- 兩面聽 6z：0
- 榮和：+10
- **合計：42 → 切上 50 符**

## 符數的進位（切上）

符數計算結果不是 10 的倍數時，**向上取整到最近的 10**：

- 20 → 20
- 21-30 → 30
- 31-40 → 40
- 41-50 → 50
- 51-60 → 60
- 61-70 → 70
- 71-80 → 80
- 81-90 → 90
- 91-100 → 100
- 101-110 → 110

## 符數一覽表

| 符數 | 說明 |
|------|------|
| 20 | 基礎值（七對子為 25） |
| 25 | 七對子專用 |
| 30 | 最常見的符數（榮和基礎） |
| 40 | 含中張刻子或暗刻時 |
| 50 | 含暗刻+特殊聽牌時 |
| 60 | 含多個暗刻時 |
| 70 | 含字牌刻子+其他加符時 |
| 80 | 含暗槓時 |
| 90+ | 極端情況（多暗槓+字牌） |
| 100-110 | 理論最大值 |

## 符數與基本點對照

基本點 = 符 × 2^(番+2)

例：30符3番 = 30 × 2^5 = 960

當基本點超過 2000 時進入滿貫體系（見點數表）。
