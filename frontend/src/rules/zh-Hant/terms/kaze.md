# 場風與自風

**分類**：基本用語

## 場風（場風）

場風指當前對局所處的風圈階段：

| 風圈 | 對應 |
|------|------|
| 東場 | 東一局 ～ 東四局 |
| 南場 | 南一局 ～ 南四局 |
| 西場（延長戰） | 西一局 ～ 西四局 |

- 東風戰只有東場
- 半莊戰有東場和南場
- 場風決定該風圈的役牌

## 自風（自風）

自風指每位玩家在該局的風位：

| 位置 | 自風 |
|------|------|
| 東家 | 東 |
| 南家 | 南 |
| 西家 | 西 |
| 北家 | 北 |

- 每局開始時，莊家是東家
- 換莊時，各家的自風會輪轉

## 役牌

當自己的自風或場風與手裡的刻子/槓子匹配時，獲得役牌役：

| 情況 | 役名 | 番數 |
|------|------|------|
| 自風刻子 | 自風牌 | 1番 |
| 場風刻子 | 場風牌 | 1番 |
| 連風刻子（自風=場風） | 連風牌 | 2番（部分規則為1番+1番） |

## 親與子

- **親（莊家）**：當前局的莊家，總是坐在東家位置
- **子（閒家）**：其餘 3 家
- 親權和牌時莊家連莊（本場 +1），子和牌時莊家輪轉
