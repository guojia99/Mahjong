# 門清（メンゼン）

**分類**：基本用語

門清（メンゼン，即門前清）指手牌未進行過任何副露（吃、碰、明槓）的狀態。

## 門清與鳴牌

| 操作 | 是否門清 |
|------|----------|
| 未進行任何副露 | 門清 |
| 吃（チー） | 非門清 |
| 碰（ポン） | 非門清 |
| 明槓（ミンカン） | 非門清 |
| 暗槓（アンカン） | **門清** |

暗槓不破壞門清狀態。

## 門清限定的役

以下役只有在門清狀態下才能成立：

| 役名 | 番數 |
|------|------|
| 立直 | 1番 |
| 雙立直 | 2番 |
| 一發 | 1番 |
| 門前清自摸和 | 1番 |
| 平和 | 1番 |
| 一杯口 | 1番 |
| 七對子 | 2番 |
| 國士無雙 | 役滿 |
| 九蓮寶燈 | 役滿 |
| 四暗刻 | 役滿 |
| 清一色（門清） | 6番 |

## 門清的價值

門清是日麻策略的核心概念之一，因為：

1. 門清限定役提供了大量額外番數
2. 立直只能在門清狀態下宣告
3. 門清自摸和本身就是 1 番
4. 平和是很容易達成的 1 番（門清榮和+兩面聽+非役牌雀頭）
