# 雀頭（對子）

**分類**：基本用語

雀頭（じゃんとう）指兩張相同牌組成的一對，在和牌牌型中作為核心配合面子使用。

## 在和牌牌型中的作用

標準牌型（4面子+1雀頭）中，雀頭是必不可少的一部分：

- 4 組面子 + 1 組雀頭 = 3×4 + 2 = **14 張**
- 雀頭也可以看作是刻子的「不完整版」

## 雀頭的符數加算

| 雀頭類型 | 加符 |
|----------|------|
| 非役牌 | +0 符 |
| 自風牌 | +2 符 |
| 場風牌 | +2 符 |
| 三元牌（白/發/中） | +2 符 |
| 連風（自風 = 場風） | +4 符 |

## 特殊情況

- **單騎聽牌**：只聽雀頭的那張牌（如已有 4 面子，差雀頭的第 2 張）
- **七對子**：7 組雀頭構成的特殊牌型
- **國士無雙**：聽 13 種幺九牌中任意 1 張的 13 面聽
