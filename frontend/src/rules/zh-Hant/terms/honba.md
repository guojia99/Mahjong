# 本場與連莊

**分類**：基本用語

## 本場（本場）

本場指莊家留在同一局的次數。每連莊一次，本場數 +1。

- 東一局一本場 → 莊家連莊 → 東一局二本場 → ...
- 本場為 0 時通常省略不提（如東一局 = 東一局零本場）

### 本場與點數

本場每增加 1，和牌點數增加：

| 方式 | 加算 |
|------|------|
| 親家自摸 | 每人 +100 |
| 親家榮和 | +300 |
| 子家自摸 | 閒家各 +100，莊家 +200 |
| 子家榮和 | +300 |

## 連莊（連荘）

莊家連莊（留在同一局）的條件：

1. **莊家和牌**（包括自摸和榮和）
2. **流局時莊家聽牌**（荒牌聽牌連莊）
3. **九種九牌流局**
4. **四風連打流局**
5. **四槓散了流局**（部分規則下）

### 連莊的標記

- 連莊時本場棒（表示本場的 100 點籌碼）增加
- 連莊不影響場風的輪轉
- 本場棒在有人和牌時收取

## 連莊對對局進度的影響

- 連莊會延長對局的時間
- 高本場時點數會顯著增加，風險和收益都更大
- 連莊多通常意味著莊家運氣好或技術好
