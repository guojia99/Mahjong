# 聽牌（テンパイ）

**分類**：基本用語

聽牌（てんぱい）指手牌只需要再獲得 1 張特定牌即可和牌的狀態。

## 聽牌的種類

### 兩面聽（リャンメン）

等待連續兩張中的任意一張。

示例：手中有 {{[mahjong] hand:3m4m}}，等待 2m 或 5m

### 嵌張聽（カンチャン）

等待兩張間隔的中間一張。

示例：手中有 {{[mahjong] hand:3m5m}}，等待 4m

### 邊張聽（ペンチャン）

等待數牌序列兩端的牌。

示例：手中有 {{[mahjong] hand:1m2m}}，等待 3m（不能等 0m）

### 單騎聽（タンキ）

只等待構成雀頭的那 1 張牌。

示例：已有 4 面子，手中持有 {{[mahjong] hand:5z}}，等待另一張 5z

### 雙碰聽（シャンポン）

同時等待兩張不同的牌來構成雀頭。

### 多面聽

等待 3 種以上牌的聽牌形式，如三面聽、四面聽等。

## 聽牌與符數

聽牌方式影響符數：

| 聽牌方式 | 加符 |
|----------|------|
| 兩面聽 | +0 符 |
| 嵌張聽 | +2 符 |
| 邊張聽 | +2 符 |
| 單騎聽 | +2 符 |
| 雙碰聽 | +0 符 |

## 流局時的聽牌

荒牌流局時，宣布聽牌的玩家可以向未聽牌的玩家收取罰符（不聽罰符）。
