# 日本麻雀規則總覽

## 基本資訊

日本麻雀（日麻、立直麻雀）是一種四人麻雀玩法，以「立直」規則為核心特色。本頁面涵蓋日麻的基本規則框架，詳細內容請參見各子頁面。

- **遊戲目的**：終局時得點最多的玩家即為勝者
- **配給原點**：每人初始持有 25000 或 30000 點（由玩家討論決定），常用 25000 點

## 牌具

使用 136 張牌（不含花牌），分為：

- **數牌**：萬子（1m～9m）、筒子（1p～9p）、索子（1s～9s），各 4 張共 108 張
- **字牌**：風牌（東南西北）+ 三元牌（白發中），各 4 張共 28 張
- **赤寶牌**：赤五萬、赤五筒、赤五索各 1 張，替換對應的普通五牌

## 對局長度

日麻以「半莊」為標準一回合單位，此外還有以下變體：

| 類型 | 說明 |
|------|------|
| **東風戰** | 僅打東場（最少 4 局），回合短，較為常見 |
| **半莊戰** | 東場 + 南場（最少 8 局），最主流的規則 |
| **一莊戰** | 東場 + 南場 + 西場 + 北場，比賽中較常見 |
| **東北戰** | 東場 + 北場，東北地方和北海道較常見 |
| **東東戰** | 打兩個東場，從東1局到東8局 |

## 玩家與坐席

- 每局 1 名**莊家**（親/東家），其餘 3 名為**閒家**（子）
- 從東家起逆時針方向依次為南家、西家、北家
- 坐在自己左邊的叫**上家**，右邊的叫**下家**，對面的叫**對家**
- 自己以外的玩家統稱為**他家**

### 起家決定

1. 將東南西北四張牌翻面混在一起，每人抽一張
2. 抽到東的人選擇自己的座位，南西北按逆時針方向順次就坐
3. 坐東位的人擲兩枚骰子，從東位起逆時針數到該點數，該玩家為臨時莊家
4. 臨時莊家再擲兩枚骰子，從該位起逆時針數到點數，該玩家為起家（正式莊家）

## 對局流程

### 配牌

- 洗牌後碼好牌牆，莊家取 14 張，閒家取 13 張
- 剩餘牌組成「山」：每人面前 17 搭（34 張），最後 7 搭為**王牌**

### 摸打

- 莊家先從 14 張中打出 1 張，然後逆時針輪流
- 每次行動：從牌山末端**摸牌** → 選擇一張**打牌**到自己的河中
- 摸牌後可以鳴牌（副露）或打牌

### 流局與續行

- 山牌摸完時無人和牌則為**流局**（荒牌）
- 流局時若有聽牌者與未聽牌者，需支付不聽罰符
- 達到特定條件時進入下一場（詳見連莊規則）

### 親權輪轉（連莊與輪莊）

- **連莊**：莊家和牌後，繼續擔任下一局莊家，本場 +1（如東一局1本場）
- **輪莊**：子家和牌後，當前莊家的下家成為下一局莊家，進入下一局名
- **流局連莊**：流局時莊家聽牌，莊家連莊（聽牌連莊規則）；部分規則要求只有和牌才連莊（和了連莊）
- 局名順序：東一局 → 東二局 → 東三局 → 東四局 → 南一局 → ... → 南四局結束

## 和牌條件

和牌（胡牌）必須同時滿足以下條件：

1. **牌型成立**：手牌（含副露）符合和牌牌型
2. **至少 1 番**：擁有至少一個有效役（翻數 ≥ 1）
3. **特殊限制**：無役時不能和牌（一番縛）

> 和牌**不是強制的**，即使能夠和牌也可以選擇不和（不宣告ツモ/ロン），摸打繼續。這在與自己沒有關係的他家立直時尤為重要。

## 鳴牌（副露）

### 吃（チー）

- 只能吃上家（左方）打出的牌
- 只能組合成**順子**（同花色連續三張）
- 吃後必須從手牌中打出一張

### 碰（ポン）

- 可以碰任何家打出的牌
- 組合成**刻子**（相同三張）
- 碰後必須從手牌中打出一張

### 槓（カン）

- **明槓**：手中已有刻子，別人打出第 4 張時槓
- **暗槓**：手中已有 4 張相同的牌，可以暗槓（保持門清）
- **加槓**：已經碰了的刻子，自己摸到第 4 張可以加槓
- 槓後從王牌中補摸 1 張（嶺上牌），槓寶牌增加 1 個

## 立直

### 立直宣言

- 門清狀態下（未副露），手牌聽牌時可以宣告「立直」
- 立直需繳納 **1000 點**的立直棒
- 立直後不能再更換手牌（只能摸切或自摸和牌）

### 立直相關役

| 役名 | 番數 | 條件 |
|------|------|------|
| 立直 | 1番 | 宣告立直後和牌 |
| 雙立直 | 2番 | 第 1 巡即宣告立直 |
| 一發 | 1番 | 立直後、下一次鳴牌前自摸和牌 |

## 特殊和牌

| 役名 | 番數 | 條件 |
|------|------|------|
| 天和 | 役滿 | 莊家配牌時即和牌 |
| 地和 | 役滿 | 子家第 1 摸即和牌（且第 1 巡無人鳴牌） |
| 海底撈月 | 1番 | 摸到山牌最後一張時和牌 |
| 河底摸魚 | 1番 | 摸到山牌最後一張後打出的牌被榮和 |
| 嶺上開花 | 1番 | 槓後補摸的牌即和牌 |
| 搶槓 | 1番 | 和別人加槓的那張牌 |
| 人和 | 役滿 | 子家配牌後，第 1 巡內榮和他家的舍牌（古役，需事先約定） |

## 點數體系

日麻的點數由**番**和**符**共同決定：

- **番（翻）**：由擁有的役種累加
- **符**：由牌型、和牌方式等決定的基礎點數
- 點數計算公式：基本點 = 符 × 2^(番+2)

### 滿貫體系

| 條件 | 名稱 | 子家榮和 | 親家榮和 | 子家自摸(閒家/莊家) | 親家自摸 |
|------|------|----------|----------|---------------------|----------|
| 3番70符 / 4番40符 / 5番 | 滿貫 | 8000 | 12000 | 2000/4000 | 4000all |
| 6-7番 | 跳滿 | 12000 | 18000 | 3000/6000 | 6000all |
| 8-10番 | 倍滿 | 16000 | 24000 | 4000/8000 | 8000all |
| 11-12番 | 三倍滿 | 24000 | 36000 | 6000/12000 | 12000all |
| 13番以上 | 累計役滿 | 32000 | 48000 | 8000/16000 | 16000all |
| 特定牌型 | 役滿 | 32000 | 48000 | 8000/16000 | 16000all |
| 特定牌型 | 雙倍役滿 | 64000 | 96000 | 16000/32000 | 32000all |

> 親家自摸為每人支付相同金額（親家のツモは各家同額）。

### 點數計算公式

- 基本點 = 符 × 2^(番+2)
- 子家榮和 = 基本點 × 4
- 親家榮和 = 基本點 × 6
- 子家自摸 = 閒家各付基本點，莊家付基本點 × 2
- 親家自摸 = 每人付基本點 × 2

## 場棒與立直棒

- **本場**：連莊時本場 +1，每本場加算基本點 × 300（榮和）或每人 × 100 / 莊家 × 200（自摸）
- **立直棒**：立直時放在場上的 1000 點籌碼，由該局和牌者全部收取

## 包牌（責任払い）

當某家的鳴牌直接導致其他家必然湊成特定役滿時，該鳴牌者需承擔全部點數（稱為包牌）：

- **大三元包**：碰了第三種三元牌的人包大三元
- **大四喜包**：碰了第四種風牌的人包大四喜
- **四槓子包**：槓了第四組槓的人包四槓子
- **大三元包**在大三元完成時，由碰了第三張三元牌的人全額支付

## 同點和了（頭跳·二家和·三家和）

同一巡中多家同時榮和同一張牌時的處理：

| 規則 | 說明 |
|------|------|
| **頭跳**（最常見） | 僅放銃者逆時針方向最近的玩家和牌 |
| **二家和** | 兩者都和牌，放銃者分別支付 |
| **三家和** | 三家都和牌或直接流局 |

## 流局規則

### 荒牌（通常流局）

- 山牌摸完無人和牌
- 有聽牌者和未聽牌者時進行不聽罰符結算

### 不聽罰符

| 情況 | 未聽者每人支付 |
|------|----------------|
| 1人聽牌 / 3人未聽 | 1000 |
| 2人聽牌 / 2人未聽 | 1500 |
| 3人聽牌 / 1人未聽 | 3000 |
| 4人聽牌 / 0人未聽 | 不支付 |

> 每位未聽玩家向每位聽牌玩家支付相同金額，不分親家子家。

### 途中流局

| 類型 | 條件 |
|------|------|
| **九種九牌** | 配牌時手牌包含 9 種以上幺九牌，可以宣告流局，莊家連莊 |
| **四風連打** | 第一巡 4 家都打出各自的風牌（東打東、南打南…），可以宣告流局 |
| **四槓散了** | 一局中累計 4 組槓完成時（部分規則下不流局） |
| **三家和流局** | 同一巡中三家同時和牌時直接流局 |

### 流局滿貫

- 流局時若某家已宣告立直且手牌為聽牌狀態，該家可以從其他未聽玩家收取滿貫點數
- 是否採用及如何處理需事先約定

## 遊戲結束與精算

### 半莊結束條件

- 南四局結束後莊家輪莊（子和牌或莊家未聽牌流局），半莊結束
- **あがりやめ規則**：南四局莊家和牌後若已為第一名，可以自行選擇是否連莊

### 被飛（ハコ/トビ）

- 採用「被飛」規則時，半莊途中若有玩家點數降到 0 以下，遊戲直接結束
- 不採用時，負分玩家向其他玩家借點棒繼續遊戲

### 延長戰

| 類型 | 條件 |
|------|------|
| **西入** | 南場結束時無人點數達到 30000（或 33300），進入西場 |
| **北入** | 西四局後仍未達到條件，進入北場 |
| **西入即終了** | 進入西場後有人達到條件時立即結束（網絡麻雀常用） |

### 精算規則

遊戲結束後根據名次進行點數調整（需事先約定是否採用）：

| 規則 | 說明 |
|------|------|
| **馬（ウマ）** | 4位支付給1位，3位支付給2位（常見：+15/-5/+5/-15 或 +20/-10/+10/-20） |
| **丘（オカ）** | 最終得點第一名獲得額外獎勵，差額從配給原點與原點之和中扣除 |

## 必須事先約定的細則

以下規則依地域和團體而異，遊戲開始前應明確：

### アリアリ / ナシナシ

| 規則 | 說明 |
|------|------|
| **アリアリ** | 承認後付（聽牌時未確定役）和食斷（有副露的斷幺九），關東地區主流 |
| **ナシナシ** | 不承認後付和食斷（完全先付），關西地區較傳統 |

### 其他細則選項

| 項目 | 選項 |
|------|------|
| 連風雀頭 | 算 2 符或算 4 符 |
| 七對子 | 25 符 2 番或 50 符 1 番 |
| 嶺上開花·海底撈月 | 是否加自摸 2 符 |
| 自摸平和 | 承認（ツモピン）或不承認 |
| 累計役滿 | 是否採用 |
| 雙倍役滿 | 是否採用，哪些是雙倍 |
| 喫換 | 不允許 / 不允許同筋 / 允許 |
| 二番縛 | 不採用 / 4本場後採用（莊家必須二番確定） |
