# 日麻符数表

## 符数基础

符（ふ）是日麻和牌时的基础点数单位，与番数共同决定最终得点。

## 符数计算规则

### 基础符数

和牌时基础符数为 **20 符**。

### 雀头加符

| 雀头类型 | 加符 |
|----------|------|
| 非役牌雀头 | +0 符 |
| 自风牌雀头 | +2 符 |
| 场风牌雀头 | +2 符 |
| 三元牌（白/發/中）雀头 | +2 符 |
| **连风雀头**（自风=场风） | +4 符（部分规则为 +2 符） |

### 面子符数

| 面子类型 | 明刻（鸣牌） | 暗刻（手牌） | 明杠 | 暗杠 |
|----------|-------------|-------------|------|------|
| 幺九牌（字牌/19m/p/s） | +4 符 | +8 符 | +16 符 | +32 符 |
| 中张牌（2-8） | +2 符 | +4 符 | +8 符 | +16 符 |

### 顺子

顺子**不加符**（+0 符），无论明暗。

### 和牌方式加符

| 和牌方式 | 加符 |
|----------|------|
| 荣和（ロン） | +10 符 |
| 自摸（ツモ） | +2 符 |
| 平和自摸 | +0 符（平和门清自摸时不加自摸 2 符） |
| 边张听牌（待 12m 或 89m 等） | +2 符 |
| 嵌张听牌（待中间一张） | +2 符 |
| 单骑听牌（待雀头） | +2 符 |

> **注意**：平和型荣和两面听时符数固定为 30 符（基础20 + 荣和10）。

### 七对子

七对子的符数**固定为 25 符**，不按上述规则计算。

## 符数计算示例

### 示例 1：基本型（30符）

{{[mahjong] hand:2m3m4m5p6p7p8s9s1s2s3s4s}}

- 基础符：20
- 顺子 ×4：0
- 雀头（非役牌）：0
- 两面听牌：0
- 荣和：+10
- **合计：30 符**

### 示例 2：含暗刻（50符）

{{[mahjong] hand:3m3m3m5p6p7p8s8s9s9s1z1z2z}}

- 基础符：20
- 中张暗刻 3m：+4
- 顺子 5p6p7p：0
- 中张暗刻 8s：+4
- 幺九暗刻 9s：+8
- 顺子 1s2s3s：0
- 雀头 1z：+2（自风或场风）
- 嵌张听 2z：+2
- 自摸：+2
- **合计：42 → 切上 50 符**

### 示例 3：含字牌暗刻（70符）

{{[mahjong] hand:7z7z7z3m4m5m1p1p1p2s3s4s5z5z6z}}

- 基础符：20
- 三元牌暗刻 7z：+8
- 顺子 3m4m5m：0
- 中张暗刻 1p：+4
- 顺子 2s3s4s：0
- 雀头 5z：+0
- 两面听 6z：0
- 荣和：+10
- **合计：42 → 切上 50 符**

## 符数的进位（切上）

符数计算结果不是 10 的倍数时，**向上取整到最近的 10**：

- 20 → 20
- 21-30 → 30
- 31-40 → 40
- 41-50 → 50
- 51-60 → 60
- 61-70 → 70
- 71-80 → 80
- 81-90 → 90
- 91-100 → 100
- 101-110 → 110

## 符数一览表

| 符数 | 说明 |
|------|------|
| 20 | 基础值（七对子为 25） |
| 25 | 七对子专用 |
| 30 | 最常见的符数（荣和基础） |
| 40 | 含中张刻子或暗刻时 |
| 50 | 含暗刻+特殊听牌时 |
| 60 | 含多个暗刻时 |
| 70 | 含字牌刻子+其他加符时 |
| 80 | 含暗杠时 |
| 90+ | 极端情况（多暗杠+字牌） |
| 100-110 | 理论最大值 |

## 符数与基本点对照

基本点 = 符 × 2^(番+2)

例：30符3番 = 30 × 2^5 = 960

当基本点超过 2000 时进入满贯体系（见点数表）。
