# 日本麻雀规则总览

## 基本信息

日本麻雀（日麻、立直麻雀）是一种四人麻将玩法，以「立直」规则为核心特色。本页面涵盖日麻的基本规则框架，详细内容请参见各子页面。

- **游戏目的**：终局时得点最多的玩家即为胜者
- **配给原点**：每人初始持有 25000 或 30000 点（由玩家讨论决定），常用 25000 点

## 牌具

使用 136 张牌（不含花牌），分为：

- **数牌**：万子（1m～9m）、筒子（1p～9p）、索子（1s～9s），各 4 张共 108 张
- **字牌**：风牌（东南西北）+ 三元牌（白發中），各 4 张共 28 张
- **赤宝牌**：赤五万、赤五筒、赤五索各 1 张，替换对应的普通五牌

## 对局长度

日麻以「半庄」为标准一回合单位，此外还有以下变体：

| 类型 | 说明 |
|------|------|
| **东风战** | 仅打东场（最少 4 局），回合短，较为常见 |
| **半庄战** | 东场 + 南场（最少 8 局），最主流的规则 |
| **一庄战** | 东场 + 南场 + 西场 + 北场，比赛中较常见 |
| **东北战** | 东场 + 北场，东北地方和北海道较常见 |
| **东东战** | 打两个东场，从东1局到东8局 |

## 玩家与坐席

- 每局 1 名**庄家**（亲/东家），其余 3 名为**闲家**（子）
- 从东家起逆时针方向依次为南家、西家、北家
- 坐在自己左边的叫**上家**，右边的叫**下家**，对面的叫**对家**
- 自己以外的玩家统称为**他家**

### 起家决定

1. 将东南西北四张牌翻面混在一起，每人抽一张
2. 抽到东的人选择自己的座位，南西北按逆时针方向顺次就坐
3. 坐东位的人掷两枚骰子，从东位起逆时针数到该点数，该玩家为临时庄家
4. 临时庄家再掷两枚骰子，从该位起逆时针数到点数，该玩家为起家（正式庄家）

## 对局流程

### 配牌

- 洗牌后码好牌墙，庄家取 14 张，闲家取 13 张
- 剩余牌组成「山」：每人面前 17 搭（34 张），最后 7 搭为**王牌**

### 摸打

- 庄家先从 14 张中打出 1 张，然后逆时针轮流
- 每次行动：从牌山末端**摸牌** → 选择一张**打牌**到自己的河中
- 摸牌后可以鸣牌（副露）或打牌

### 流局与续行

- 山牌摸完时无人和牌则为**流局**（荒牌）
- 流局时若有听牌者与未听牌者，需支付不听罚符
- 达到特定条件时进入下一场（详见连庄规则）

### 亲权轮转（连庄与轮庄）

- **连庄**：庄家和牌后，继续担任下一局庄家，本场 +1（如东一局1本场）
- **轮庄**：子家和牌后，当前庄家的下家成为下一局庄家，进入下一局名
- **流局连庄**：流局时庄家听牌，庄家连庄（听牌连庄规则）；部分规则要求只有和牌才连庄（和了连庄）
- 局名顺序：东一局 → 东二局 → 东三局 → 东四局 → 南一局 → ... → 南四局结束

## 和牌条件

和牌（胡牌）必须同时满足以下条件：

1. **牌型成立**：手牌（含副露）符合和牌牌型
2. **至少 1 番**：拥有至少一个有效役（翻数 ≥ 1）
3. **特殊限制**：无役时不能和牌（一番缚）

> 和牌**不是强制的**，即使能够和牌也可以选择不和（不声明ツモ/ロン），摸打继续。这在与自己没有关系的他家立直时尤为重要。

## 鸣牌（副露）

### 吃（チー）

- 只能吃上家（左方）打出的牌
- 只能组合成**顺子**（同花色连续三张）
- 吃后必须从手牌中打出一张

### 碰（ポン）

- 可以碰任何家打出的牌
- 组合成**刻子**（相同三张）
- 碰后必须从手牌中打出一张

### 杠（カン）

- **明杠**：手中已有刻子，别人打出第 4 张时杠
- **暗杠**：手中已有 4 张相同的牌，可以暗杠（保持门清）
- **加杠**：已经碰了的刻子，自己摸到第 4 张可以加杠
- 杠后从王牌中补摸 1 张（岭上牌），杠宝牌增加 1 个

## 立直

### 立直宣言

- 门清状态下（未副露），手牌听牌时可以宣告「立直」
- 立直需缴纳 **1000 点**的立直棒
- 立直后不能再更换手牌（只能摸切或自摸和牌）

### 立直相关役

| 役名 | 番数 | 条件 |
|------|------|------|
| 立直 | 1番 | 宣告立直后和牌 |
| 双立直 | 2番 | 第 1 巡即宣告立直 |
| 一发 | 1番 | 立直后、下一次鸣牌前自摸和牌 |

## 特殊和牌

| 役名 | 番数 | 条件 |
|------|------|------|
| 天和 | 役满 | 庄家配牌时即和牌 |
| 地和 | 役满 | 子家第 1 摸即和牌（且第 1 巡无人鸣牌） |
| 海底捞月 | 1番 | 摸到山牌最后一张时和牌 |
| 河底摸鱼 | 1番 | 摸到山牌最后一张后打出的牌被荣和 |
| 岭上开花 | 1番 | 杠后补摸的牌即和牌 |
| 抢杠 | 1番 | 和别人加杠的那张牌 |
| 人和 | 役满 | 子家配牌后，第 1 巡内荣和他家的舍牌（古役，需事先约定） |

## 点数体系

日麻的点数由**番**和**符**共同决定：

- **番（翻）**：由拥有的役种累加
- **符**：由牌型、和牌方式等决定的基础点数
- 点数计算公式：基本点 = 符 × 2^(番+2)

### 满贯体系

| 条件 | 名称 | 子家荣和 | 亲家荣和 | 子家自摸（闲家/庄家） | 亲家自摸 |
|------|------|----------|----------|----------------------|----------|
| 3番70符 / 4番40符 / 5番 | 满贯 | 8000 | 12000 | 2000 / 4000 | 4000all |
| 6-7番 | 跳满 | 12000 | 18000 | 3000 / 6000 | 6000all |
| 8-10番 | 倍满 | 16000 | 24000 | 4000 / 8000 | 8000all |
| 11-12番 | 三倍满 | 24000 | 36000 | 6000 / 12000 | 12000all |
| 13番以上 | 累计役满 | 32000 | 48000 | 8000 / 16000 | 16000all |
| 特定牌型 | 役满 | 32000 | 48000 | 8000 / 16000 | 16000all |
| 双倍役满 | — | 64000 | 96000 | 16000 / 32000 | 32000all |

> 亲家自摸为每人支付相同金额（如满贯时每人付 4000，三家共 12000）。

### 点数计算公式

- **基本点** = 符 × 2^(番+2)
- **子家荣和** = 基本点 × 4
- **亲家荣和** = 基本点 × 6
- **子家自摸** = 闲家各付基本点，庄家付基本点 × 2
- **亲家自摸** = 每人付基本点 × 2

## 场棒与立直棒

- **本场**：连庄时本场 +1，每本场加算基本点 × 300（荣和）或每人 × 100 / 庄家 × 200（自摸）
- **立直棒**：立直时放在场上的 1000 点筹码，由该局和牌者全部收取

## 包牌（責任払い）

当某家的鸣牌直接导致其他家必然凑成特定役满时，该鸣牌者需承担全部点数（称为包牌）：

- **大三元包**：碰了第三种三元牌的人包大三元
- **大四喜包**：碰了第四种风牌的人包大四喜
- **四杠子包**：杠了第四组杠的人包四杠子
- **大三元包**在大三元完成时，由碰了第三张三元牌的人全额支付

## 同点和了（头跳·二家和·三家和）

同一巡中多家同时荣和同一张牌时的处理：

| 规则 | 说明 |
|------|------|
| **头跳**（最常见） | 仅放铳者逆时针方向最近的玩家和牌 |
| **二家和** | 两者都和牌，放铳者分别支付 |
| **三家和** | 三家都和牌或直接流局 |

## 流局规则

### 荒牌（通常流局）

- 山牌摸完无人和牌
- 有听牌者和未听牌者时进行不听罚符结算

### 不听罚符

| 情况 | 未听者每人支付 |
|------|----------------|
| 1人听牌 / 3人未听 | 1000 |
| 2人听牌 / 2人未听 | 1500 |
| 3人听牌 / 1人未听 | 3000 |
| 4人听牌 / 0人未听 | 不支付 |

> 每位未听玩家向每位听牌玩家支付相同金额，不分亲家子家。

### 途中流局

| 类型 | 条件 |
|------|------|
| **九种九牌** | 配牌时手牌包含 9 种以上幺九牌，可以宣告流局，庄家连庄 |
| **四风连打** | 第一巡 4 家都打出各自的风牌（东打东、南打南…），可以宣告流局 |
| **四杠散了** | 一局中累计 4 组杠完成时（部分规则下不流局） |
| **三家和流局** | 同一巡中三家同时和牌时直接流局 |

### 流局满贯

- 流局时若某家已宣告立直且手牌为听牌状态，该家可以从其他未听玩家收取满贯点数
- 是否采用及如何处理需事先约定

## 游戏结束与精算

### 半庄结束条件

- 南四局结束后庄家轮庄（子和牌或庄家未听牌流局），半庄结束
- **あがりやめ规则**：南四局庄家和牌后若已为第一名，可以自行选择是否连庄

### 被飞（ハコ/トビ）

- 采用「被飞」规则时，半庄途中若有玩家点数降到 0 以下，游戏直接结束
- 不采用时，负分玩家向其他玩家借点棒继续游戏

### 延长战

| 类型 | 条件 |
|------|------|
| **西入** | 南场结束时无人点数达到 30000（或 33300），进入西场 |
| **北入** | 西四局后仍未达到条件，进入北场 |
| **西入即终了** | 进入西场后有人达到条件时立即结束（网络麻雀常用） |

### 精算规则

游戏结束后根据名次进行点数调整（需事先约定是否采用）：

| 规则 | 说明 |
|------|------|
| **马（ウマ）** | 4位支付给1位，3位支付给2位（常见：+15/-5/+5/-15 或 +20/-10/+10/-20） |
| **丘（オカ）** | 最终得点第一名获得额外奖励，差额从配给原点与原点之和中扣除 |

## 必须事先约定的细则

以下规则依地域和团体而异，游戏开始前应明确：

### アリアリ / ナシナシ

| 规则 | 说明 |
|------|------|
| **アリアリ** | 承认后付（听牌时未确定役）和食断（有副露的断幺九），关东地区主流 |
| **ナシナシ** | 不承认后付和食断（完全先付），关西地区较传统 |

### 其他细则选项

| 项目 | 选项 |
|------|------|
| 连风雀头 | 算 2 符或算 4 符 |
| 七对子 | 25 符 2 番或 50 符 1 番 |
| 岭上开花·海底捞月 | 是否加自摸 2 符 |
| 自摸平和 | 承认（ツモピン）或不承认 |
| 累计役满 | 是否采用 |
| 双倍役满 | 是否采用，哪些是双倍 |
| 吃换 | 不允许 / 不允许同筋 / 允许 |
| 二番缚 | 不采用 / 4本场后采用（庄家必须二番确定） |
