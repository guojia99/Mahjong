# 面子

**分类**：基本用语

面子（めんつ）指构成和牌牌型的基本组合单位。面子分为三种：

## 顺子（ジュンツ）

同花色中连续三张数牌组成的组合。

示例：{{[mahjong] chi:2m3m4m}}、{{[mahjong] chi:5p6p7p}}、{{[mahjong] chi:1s2s3s}}

- 只能由数牌组成（字牌不能组成顺子）
- 必须同花色且连续
- 不能跨花色

## 刻子（コウツ）

三张相同牌的组合。

示例：{{[mahjong] pon:5z5z5z}}、{{[mahjong] pon:3m3m3m}}、{{[mahjong] pon:9p9p9p}}

- 任何牌都可以组成刻子
- **明刻**：通过碰别人打出的牌组成
- **暗刻**：手牌中自然凑齐的三张相同牌

## 杠子（カンツ）

四张相同牌的组合（刻子的扩展）。

- **明杠**：碰后别人打出第 4 张，或手中有 3 张别人打出第 4 张
- **暗杠**：手牌中有 4 张相同的牌，自己宣布暗杠
- **加杠**：已经碰了的刻子，自己摸到第 4 张后加杠
- 杠后需从王牌补摸 1 张（岭上牌），同时增加 1 个杠宝牌指示牌

### 符数差异

| 面子 | 中张牌 | 幺九牌 |
|------|--------|--------|
| 顺子 | 0 符 | 0 符 |
| 明刻 | +2 符 | +4 符 |
| 暗刻 | +4 符 | +8 符 |
| 明杠 | +8 符 | +16 符 |
| 暗杠 | +16 符 | +32 符 |
