# 门清（メンゼン）

**分类**：基本用语

门清（メンゼン，即门前清）指手牌未进行过任何副露（吃、碰、明杠）的状态。

## 门清与鸣牌

| 操作 | 是否门清 |
|------|----------|
| 未进行任何副露 | 门清 |
| 吃（チー） | 非门清 |
| 碰（ポン） | 非门清 |
| 明杠（ミンカン） | 非门清 |
| 暗杠（アンカン） | **门清** |

暗杠不破坏门清状态。

## 门清限定的役

以下役只有在门清状态下才能成立：

| 役名 | 番数 |
|------|------|
| 立直 | 1番 |
| 双立直 | 2番 |
| 一发 | 1番 |
| 门前清自摸和 | 1番 |
| 平和 | 1番 |
| 一杯口 | 1番 |
| 七对子 | 2番 |
| 国士无双 | 役满 |
| 九莲宝灯 | 役满 |
| 四暗刻 | 役满 |
| 清一色（门清） | 6番 |

## 门清的价值

门清是日麻策略的核心概念之一，因为：

1. 门清限定役提供了大量额外番数
2. 立直只能在门清状态下宣告
3. 门清自摸和本身就是 1 番
4. 平和是很容易达成的 1 番（门清荣和+两面听+非役牌雀头）
