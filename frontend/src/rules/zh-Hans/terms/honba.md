# 本场与连庄

**分类**：基本用语

## 本场（本場）

本场指庄家留在同一局的次数。每连庄一次，本场数 +1。

- 东一局一本场 → 庄家连庄 → 东一局二本场 → ...
- 本场为 0 时通常省略不提（如东一局 = 东一局零本场）

### 本场与点数

本场每增加 1，和牌点数增加：

| 方式 | 加算 |
|------|------|
| 亲家自摸 | 每人 +100 |
| 亲家荣和 | +300 |
| 子家自摸 | 闲家各 +100，庄家 +200 |
| 子家荣和 | +300 |

## 连庄（連荘）

庄家连庄（留在同一局）的条件：

1. **庄家和牌**（包括自摸和荣和）
2. **流局时庄家听牌**（荒牌听牌连庄）
3. **九种九牌流局**
4. **四风连打流局**
5. **四杠散了流局**（部分规则下）

### 连庄的标记

- 连庄时本场棒（表示本场的 100 点筹码）增加
- 连庄不影响场风的轮转
- 本场棒在有人和牌时收取

## 连庄对对局进度的影响

- 连庄会延长对局的时间
- 高本场时点数会显著增加，风险和收益都更大
- 连庄多通常意味着庄家运气好或技术好
