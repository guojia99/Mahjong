# 场风与自风

**分类**：基本用语

## 场风（場風）

场风指当前对局所处的风圈阶段：

| 风圈 | 对应 |
|------|------|
| 东场 | 东一局 ～ 东四局 |
| 南场 | 南一局 ～ 南四局 |
| 西场（延长战） | 西一局 ～ 西四局 |

- 东风战只有东场
- 半庄战有东场和南场
- 场风决定该风圈的役牌

## 自风（自風）

自风指每位玩家在该局的风位：

| 位置 | 自风 |
|------|------|
| 东家 | 东 |
| 南家 | 南 |
| 西家 | 西 |
| 北家 | 北 |

- 每局开始时，庄家是东家
- 换庄时，各家的自风会轮转

## 役牌

当自己的自风或场风与手里的刻子/杠子匹配时，获得役牌役：

| 情况 | 役名 | 番数 |
|------|------|------|
| 自风刻子 | 自风牌 | 1番 |
| 场风刻子 | 场风牌 | 1番 |
| 连风刻子（自风=场风） | 连风牌 | 2番（部分规则为1番+1番） |

## 亲与子

- **亲（庄家）**：当前局的庄家，总是坐在东家位置
- **子（闲家）**：其余 3 家
- 亲权和牌时庄家连庄（本场 +1），子和牌时庄家轮转
